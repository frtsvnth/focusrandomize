# Sprint Review Show

Статическое веб-приложение для выбора очередности выступления команд на Sprint Review.

## Функциональность

- **11 игровых механик**: Колесо Фортуны, Автомат, Скачки, Хватайка, Тайные карты,
  Битва стикменов, Лифт, Торнадо, Кости, Гладиаторы, Похищение.
- **Две версии движка**:
  - **V1** — проверенная классика.
  - **V2** — новая презентационная оболочка с canvas-рендерингом, частицами,
    кинематографичным раскрытием результата и процедурным звуком. Все механики
    полностью переработаны.
- **5 тем оформления**: тёмная, светлая, неон, ретро, космос.
- **Режим ведущего** — полноэкранное шоу для онлайн-встречи.
- **Админ-панель** — команды, скрытые сценарии очередности, механики, темы, бэкап.
- **Управляемая случайность** — визуально случайный выбор с возможностью предопределить результат.
- **Честный случай** — настоящий random, когда сценарий не задан.
- **Сессии** — выбранные команды удаляются только из текущей сессии, мастер-список сохраняется.
- **Экспорт/импорт JSON** — бэкап и перенос настроек, с валидацией через zod.
- **Звуки и reduced-motion** — уважает `prefers-reduced-motion` (с ручным override в настройках).

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Сборка и тесты

```bash
npm run build   # сборка в dist/
npm test        # vitest
```

## Деплой на GitHub Pages

Деплой автоматизирован через GitHub Actions (`.github/workflows/deploy.yml`):
при пуше в ветку `main` выполняется `npm ci`, `npm run build`, артефакт из `dist`
публикуется в GitHub Pages. Отдельных действий не требуется.

## Управление

- **Пробел / Enter** — запуск выбора или переход к следующей команде.
- **F** — полноэкранный режим.
- **#admin** — переключение в админ-панель (или кнопка «⚙️ Админ» в шоу).

## Как включить scripted mode

1. Перейдите в Админ.
2. В разделе **Очередь выступлений** задайте:
   - **Полный порядок** — список команд по очереди.
   - **Следующая команда** — команда, которая выйдет следующей принудительно.
   - **Команда, выступающая последней** — фиксирует финал.
3. Вернитесь в шоу и запустите выбор.

> ID команд можно посмотреть в отладочной панели админки или в экспортированном JSON.

## Ограничения безопасности

- PIN-код и админ-доступ реализованы исключительно на уровне UI.
- Все данные хранятся в `localStorage` на устройстве пользователя.
- Любой, у кого есть доступ к устройству или devtools, может изменить состояние.
- Это не backend-аутентификация и не защита данных.

## Архитектура

- `src/domain/` — чистые типы, сущности и zod-схемы валидации.
- `src/engine/` — `selectNextTeam`, единый движок выбора.
- `src/mechanics/` — классические (V1) адаптеры игровых механик.
- `src/mechanics-v2/` — адаптеры V2: canvas-рендеринг, частицы, процедурный звук.
- `src/state/` — React Context + reducer + localStorage persistence.
- `src/hooks/` — `useSelection`, `useSound`, `useSoundV2`.
- `src/components/` — UI режима ведущего и админ-панели.
